Bin Pipeline: Viral DNA Classification

Onderzoeksvraag: “Hoe kunnen we DNA-data van verschillende soorten virussen specifiek classificeren en visualiseren?”

Inleiding

Voor de BIN toolbox bouwen we een interface die bio-informatica tools aanstuurt. Het doel is om hobbyisten, studenten en onderzoekers een toegankelijke manier te bieden om virussen te diagnosticeren, vergelijkbaar met systemen van het RIVM.

Gebruikte Tools: FASTP KRAKEN2 KRONA

Requirements

  • Linux (of WSL) & Python 3.x
  • libisal-dev & libdeflate-dev
  • build-essential & zlib1g-dev
  • Krona & Flask

Installation Instructions

FASTP

Installeer requirements en compileer de binary:

sudo apt install libdeflate-dev libisal-dev build-essential
wget https://github.com/OpenGene/fastp/archive/refs/tags/v1.1.0.tar.gz
tar -xf v1.1.0.tar.gz
cd fastp-1.1.0/
make -j
sudo make install

Kraken2 & Krona

Installeer Krona visualisatie en daarna de Kraken2 engine:

# Krona
git clone https://github.com/marbl/Krona.git
cd Krona/KronaTools
sudo ./install.pl
mkdir taxonomy && ./updateTaxonomy

# Kraken2
wget https://github.com/DerrickWood/kraken2/archive/refs/tags/v2.17.1.tar.gz
tar -xf v2.17.1.tar.gz
cd kraken2-2.17.1/
chmod +x install_kraken2.sh
sudo ./install_kraken2.sh /usr/local/bin

Database & Test Run

Download de virology database en koppel deze via een symlink:

mkdir viral_db && cd viral_db
wget [DATABASE_URL]
tar -xf viral-jgi-krakend-all
sudo ln -s $(pwd) /virology_db

Start de analyse:

kraken2 --db /virology_db --threads 4 --report out.txt *.fasta

Bin Pipeline: Het Classificeren van Virussen

Ons proces in het bouwen van een interactieve bio-informatica interface.

Het Project

Voor de opdracht van de BIN toolbox kregen wij de taak om een website te bouwen die een complexe bio-informatica pipeline aanstuurt. Onze opdrachtgevers, Ronald W. en Peter K., vroegen ons om een interface te creëren die niet alleen tools aanroept, maar ook interim-rapporten deelt met de gebruiker.

Wij hebben ons gericht op een doelgroep van hobbyisten, studenten en onderzoekers die snel inzicht willen krijgen in DNA-sequenties.

“Hoe kunnen we DNA-data van verschillende soorten virussen specifiek classificeren en visualiseren?”

Onze Keuzes & Tools

De keuze van de tools was vrij. Wij hebben specifiek gekozen voor een combinatie van snelheid en visuele kracht:

  • FastP: Voor de noodzakelijke kwaliteitscontrole en preprocessing van de ruwe data.
  • Kraken2: Vanwege de ongekende snelheid in het classificeren van DNA-reads tegen een database.
  • Krona: Om de complexe data om te zetten in interactieve cirkeldiagrammen die voor iedereen begrijpelijk zijn.

Hoe we het hebben aangepakt

1. De Omgeving Opzetten

We zijn begonnen met het inrichten van een Linux-omgeving (WSL). Hierbij moesten we diverse dependencies installeren om de tools te kunnen compileren. Denk hierbij aan bibliotheken zoals libisal en libdeflate voor optimale snelheid.

2. Installatie & Compilatie

In plaats van kant-en-klare pakketten, hebben we de broncode van FastP en Kraken2 zelf gecompileerd. Dit stelde ons in staat om de tools direct vanuit de terminal (make -j) te installeren op onze systemen.

3. Database Management

Een cruciaal onderdeel was de virology database. We hebben de JGI-database binnengehaald en via symbolic links (ln -s) gekoppeld aan onze pipeline. Hierdoor bleef onze mappenstructuur overzichtelijk, terwijl de zware data op de juiste plek stond.

Het Resultaat

Uiteindelijk hebben we een systeem gebouwd waar een simpele test run direct resultaat geeft. Door het aanroepen van Kraken2 op een set FASTA-bestanden, genereert onze pipeline een gedetailleerd rapport (out.txt) dat vervolgens door Krona gevisualiseerd kan worden.

Hiermee imiteren we de professionele tools die instanties zoals het RIVM gebruiken voor snelle virusdiagnostiek.

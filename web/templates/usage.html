Hoe gebruik je de pipeline?

Course: BIN Toolbox | Team: Jesse & Robin

Deze website is gemaakt om FASTQ-bestanden te analyseren. De pipeline werkt in twee stappen: eerst worden de reads opgeschoond met fastp, daarna worden ze geanalyseerd met Kraken2 om te bepalen van welke organismen ze afkomstig zijn.

1. FASTQ-bestand uploaden

Bovenaan de pagina upload je een FASTQ-bestand. Dit bestand bevat de ruwe reads die gebruikt worden in de analyse. Nadat je een bestand hebt gekozen, gebruikt de pipeline dit bestand voor alle volgende stappen.

2. fastp configuratie

In dit gedeelte stel je in hoe de reads worden aangepast voordat ze verder worden gebruikt.

Quality threshold geeft aan welke basekwaliteit minimaal nodig is.

Trim adapters verwijdert adaptersequenties uit de reads.

Minimum length bepaalt hoe kort een read mag zijn.

Maximum length bepaalt hoe lang een read mag zijn.

Cut front verwijdert bases aan het begin van de read.

Cut tail verwijdert bases aan het einde van de read.

Deduplication verwijdert identieke reads en staat standaard uit.

3. Kraken2 configuratie

Confidence threshold bepaalt wanneer een read wordt toegewezen.

Paired reads gebruik je bij paired-end data.

Use scientific names toont wetenschappelijke namen.

Minimum base quality bepaalt welke bases worden gebruikt.

4. Analyse uitvoeren

Klik op Run analysis om de pipeline te starten. Hoe lang dit duurt hangt af van het bestand en de instellingen.
